# Agentronics brand assets

- `agentronics-mark.svg` — the "A" mark in Copper `#E8763A`, transparent background. Traced from the master logo (2000×2000) and cropped to the glyph.
- `agentronics-favicon.svg` — the mark on a PCB Black `#0D1A16` rounded square (same as `app/icon.svg`).

Palette, type and usage rules: see the "Circuit Copper" design guide (copper = actions and circuit traces only; verdigris `#2BB39A` = done / ready / good).
The React version lives in `components/ui/Logo.tsx` (`MARK_PATH`).
