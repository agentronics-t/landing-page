# Agentronics brand assets

- `agentronics-favicon.svg`: the logo. Lime `#D4FF3A` "A" on a red `#FF4D1F` rounded square (same as `app/icon.svg` and `public/home-assets/favicon.svg`).
- `agentronics-mark.svg`: the "A" alone in lime, transparent background, for dark surfaces.

Palette: ink `#0B0B0C`, paper `#FFFFFF`, lime `#D4FF3A` (go, ready, allow, every primary action), amber `#FFB224` (partly ready, ask first), red `#FF4D1F` (not ready, deny, loss). Type: Funnel Display, Funnel Sans, Martian Mono.
The design system itself is `public/home-assets/styles.css`; the React version of the logo is `components/ui/Logo.tsx`.
