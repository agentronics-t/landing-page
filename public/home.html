FAQ

Questions buyers ask before they start.

What does the Agent Readiness Score measure?

A number from 0 to 100 from 12 checks in three groups: can agents find your site, read it, and act on it. Each check shows what’s wrong and how to fix it.

Do I have to give you access to my code?

Not for the score, which only reads public pages. For fixes, you install the Agentronics GitHub App on the repos you choose. Every change arrives as a pull request your team reviews before merging.

Can I trust AI-written code?

You don’t have to trust it blindly. Every change is a normal pull request with an explanation, and your team reviews it before merging.

Will this change how my site looks?

No. Fixes are invisible to people.

Will it hurt or help my Google rankings?

It won’t hurt. Many fixes are things search engines already reward. llms.txt is for AI tools, and Google ignores it for rankings. Agents never see different content from people.

Are AI agents really visiting websites?

Yes. AI-referred visits to US retail sites rose about 693% in the 2025 holidays (Adobe Analytics), and those visitors converted better. Your dashboard shows which agents visit your own site.

Which AI agents does this help?

Any agent that reads web pages, such as ChatGPT, Claude, Perplexity and Gemini. Browsers supporting WebMCP can also call your site’s actions directly.

Can agents do things I don’t want?

No. For each action you choose allow, ask first, or deny.

How long does setup take? Do I need a developer?

The score takes 30 seconds, and connecting GitHub takes minutes. Someone who can approve a pull request reviews the changes.

My score is already high. Do I still need this?

Maybe not today. But sites change, and one new form can break agent access. Paid plans re-check after every code change and alert you.

Is Free really free?

Yes. Free is $0 for one site, with Agent Nic included. Merged fixes stay in your code even if you later cancel a paid plan.
